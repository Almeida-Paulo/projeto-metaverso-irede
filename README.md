# 🌳 CarbonVerse VR

### Protótipo de Floresta Virtual para Projetos de Créditos de Carbono

**👨‍💻 Autor:** Paulo Almeida
**📚 Trilha:** 1

---

## 🌎 Sobre o Projeto

O **CarbonVerse VR** é um protótipo desenvolvido na plataforma Unity como atividade prática da disciplina de Metaverso e Realidade Virtual.

O projeto apresenta uma floresta virtual simples que representa a ideia de um futuro ambiente imersivo voltado para a visualização de projetos de créditos de carbono. O cenário foi construído para demonstrar como tecnologias de Realidade Virtual podem ser utilizadas para aproximar investidores, parceiros e demais stakeholders de informações relacionadas a projetos ambientais.

---

## 🎯 Objetivo

O objetivo deste protótipo é ilustrar um conceito de ambiente virtual onde participantes possam visualizar, de forma imersiva, uma propriedade vinculada a um projeto de crédito de carbono.

A proposta é demonstrar como um espaço virtual pode servir como ferramenta de apresentação e acompanhamento de iniciativas ambientais, permitindo uma experiência mais envolvente do que documentos ou apresentações convencionais.

---

## 🥽 O Protótipo

Nesta versão foram implementados elementos básicos para representar a ideia do projeto:

🌳 Uma floresta virtual composta por árvores distribuídas no ambiente;

🪧 Uma placa de identificação contendo o nome da floresta ou do projeto de crédito de carbono;

🌎 Um ambiente explorável em Realidade Virtual desenvolvido na Unity;

🎮 Estrutura inicial para futuras expansões e inclusão de funcionalidades interativas.

---

## 🚀 Possibilidades Futuras

Embora esta versão seja apenas um protótipo conceitual, o projeto pode evoluir para incluir funcionalidades como:

* Visualização de diferentes espécies de árvores;
* Exibição da quantidade de árvores plantadas;
* Painéis informativos e infográficos ambientais;
* Indicadores de captura de carbono;
* Informações geográficas da propriedade;
* Interação entre usuários em ambiente virtual compartilhado;
* Integração com dados reais de projetos ambientais.

---
